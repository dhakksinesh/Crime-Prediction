# Crime Analysis and Prediction Based on Machine Learning Algorithms

A web app that analyzes and predicts crime data across Indian states using machine learning algorithms.

## Features
- Visual analysis of rape cases reported across states and years
- State-wise crime data exploration
- Crime prediction using multiple machine learning algorithms
- Accuracy comparison between algorithms

## Algorithms Used
- Random Forest
- Support Vector Machine (SVM)
- Linear Regression
- K-Nearest Neighbors (KNN)

## Dataset
- Crime data across Indian states from 2010 to 2019

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas, NumPy
- Plotly, Seaborn, Matplotlib
